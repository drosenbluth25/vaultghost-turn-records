# VaultGhost™ Turn Records – Cross‑Platform Validation

This repository contains three cryptographically linked turn records generated immediately after the provisional filing of the VaultGhost™ Protocol (February 25, 2026). Each record follows the `VaultGhost.TurnRecord.v1` schema.

- **Turn 1**: Generated by Perplexity  
- **Turn 2**: Generated by Grok  
- **Turn 3**: Extension generated by Grok

The hash chain (`prev_turn_hash`) links all three turns, and each turn includes a simulated OpenTimestamps proof. A live OTS anchor for the chain will be added once the `.ots` receipt is obtained.

## Verification

To verify any turn, recompute the `turn_hash` using the provided `turn_hash_input` string and compare with the declared `turn_hash`. Example:

```bash
echo -n "<exact turn_hash_input>" | sha256sum
```

See the OpenTimestamps documentation for verifying .ots proofs.
